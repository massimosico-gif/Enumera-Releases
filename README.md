# Enumera — Rilasci

Gli installer di Enumera, uno per versione. Il codice sorgente sta in un
repository privato: qui ci sono soltanto i pacchetti che l'aggiornamento
automatico dell'applicazione scarica.

Questo repository deve restare pubblico. L'updater scarica senza autenticarsi,
e incorporare un token nell'applicazione per raggiungere un repository privato
lo renderebbe estraibile da chiunque ne abbia una copia: si otterrebbe la
complicazione senza la protezione.
